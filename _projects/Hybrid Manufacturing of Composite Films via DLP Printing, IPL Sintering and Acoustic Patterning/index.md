# Hybrid Manufacturing of Composite Films via DLP Printing, IPL Sintering, and Acoustic Patterning

This project demonstrates a hybrid manufacturing route for producing conductive composite thin films by combining additive manufacturing with post-processing and surface patterning. The goal was to overcome the limitations of each method when used individually and create a functional film with improved electrical performance.

## Objective

The project focused on fabricating metal-polymer composite films using:

- DLP printing for precise layer-by-layer pattern generation
- IPL sintering for rapid densification and electrical connectivity
- Acoustic patterning to guide material arrangement and improve functional behavior

## Key outcomes

- Improved electrical conductivity through hybrid processing
- Better control of film microstructure and material distribution
- Evaluation of electrical and microstructural performance using optical microscopy and electrical testing

## Process flow

1. Develop a functional metal-photopolymer ink system
2. Print the desired geometry using DLP technology
3. Apply IPL sintering to improve particle connectivity
4. Use acoustic patterning to tune the final film architecture
5. Characterize the structure and electrical response
